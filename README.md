# Stack Overflow Clone

🔗 [Live Demo](https://dip-sama.github.io/stackoverflow-clone/stackoverflow-clone/stackoverflow-clone.html)

A front-end clone of the popular Q&A platform [Stack Overflow](https://stackoverflow.com/) built using **HTML**, **CSS**, and **JavaScript**. This project is designed to showcase UI structure, interactivity, and layout design using only front-end technologies.


## 📌 Features

- 🔷 Clean and responsive layout
- 🟧 Navigation bar similar to Stack Overflow
- 🟨 Sidebar for filters or additional links
- 🟦 Question and answer feed UI
- ⚪ Footer section with external links and branding
- 🧩 HTML/CSS only — no back-end/database


## 🚀 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
